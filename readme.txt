Lightweight plugin to hide admin notices.

== Description ==

Tired of endless plugin nags and promotional banners cluttering your WordPress dashboard? Admin Notices Hide Lite is a super lightweight utility plugin that permanently hides annoying admin notices with absolute simplicity.

If you are looking for a no-fluff solution that doesn't load extra files, this is for you.

* Zero CSS & JavaScript: Hides the notices efficiently without adding unnecessary code bloat to your site's backend.
* Minimal Settings Page: A clean, straightforward admin menu to easily toggle the notice-hiding feature on or off.
* Streamlined Workflow: Instantly unclutter your screen so you can focus on what matters most.
