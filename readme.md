# Admin Notices Hide Lite

Lightweight plugin to hide admin notices.

## Description

Super lightweight Wordpress plugin to hide admin notices.

## Getting Started

### Dependencies

* None

### Installing

* Plugins > Add Plugins > Upload Plugin > Choose File > Install Now
* Activate
